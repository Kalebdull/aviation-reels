# Playbook: what makes an Aviation Reels lesson work

The series: **30-second Instagram Reels that make aviation knowledge simple.** One idea per reel, explained so a non-pilot follows it and a student pilot saves it.

These rules come from posted results (see `lessons.md`). When a rule here and a lesson there disagree, the newer lesson wins. Update this file when that happens.

## The audience
- Curious non-pilots who love planes, student pilots, and pilots brushing up for a checkride.
- They scroll fast. Recognition in the first second stops the scroll. Jargon in the first second loses them.

## The four drivers (apply to every script and every shot list)
1. **Familiarity first.** Open on something the viewer already knows or feels: an escalator, a car speedometer, a lighthouse, ears popping, "your body lies to you". Tie the aviation idea to everyday life before any jargon.
2. **The prediction trap.** Set up a pattern the viewer thinks they can predict, then break it. "You feel level…" then reveal a 32° bank. "Which way does the needle go?" then show it go the other way. The lesson lands as a punchline, not a lecture.
3. **The payoff is the information.** The key fact (030 radial, 1 inch per 1,000 ft, 5 satellites) is the most satisfying moment. Time it with the biggest visual reveal of the reel.
4. **Show the mechanism, not the dial.** Every gauge or system gets a working demo: air rams into the pitot tube and pushes the needle; the aneroid wafers swell as the air thins; the VSI's calibrated leak lags. A plain dial on its own is not a lesson.

## Hook formulas (pick one per reel, spoken in the first second, visible on frame 0)
- **Shocking stat:** "A pilot with no instrument training loses control in about 178 seconds."
- **Curiosity gap:** "Here's how your airplane knows which one it's on."
- **Quiz / commitment:** "20 knots of crosswind at 120 knots = ? degrees." Quiz hooks drive saves.
- **Contrast:** "Before GPS, pilots crossed the country using this."
- **Specificity + authority:** real numbers beat vague claims (200 ft, 360 radials, 1 inHg per 1,000 ft).
- **Effort reduction:** "The only 3 gauges you need to understand."
- **Identity:** "If you're a student pilot, save this for your checkride."
- **Familiar object:** "Your car's speedometer has a cousin in every cockpit."

Rotate them. Note in `episodes.md` which one each reel used, so `lessons.md` can learn which ones work.

## Script rules
- **Length:** 70–85 words, about 30 seconds of CapCut text-to-speech. Hard ceiling of 40 s spoken. If the topic needs more, make it Part 1 / Part 2. Part 2s ride Part 1's wave, so post them close together.
- **Shape:** super simple → complex. Start with what anyone recognises; end with what a student pilot would save.
- **Voice:** a calm, plain-English instructor. FAA-accurate. Explain any jargon the moment it appears ("the pitot tube, a little scoop that faces the wind").
- **One idea.** If you need "and also", cut it.
- **Lines:** 6–10 spoken lines, one thought each, 1.5–4 s each. Every line gets its own visual beat.
- **Don't caption a spoken title.** If a line is just the topic name, mark it `| -` in `lines.txt`.
- **Never read the gag.** On-screen jokes and keyword slams don't have to be spoken; the voice says only what makes sense spoken.
- **Ending:** a loop plus an action. Either a question whose answer goes in the pinned comment ("Which way does the flag flip? Comment below"), or "Save this for your checkride." The last frame flows back into frame 0.
- **Fact-check everything** against FAA sources (PHAK, AIM, AFH, IFH, ACS) or a primary study. Put each claim and its source in `facts.md`. No source, no claim.

## Structure of a 30-second reel (a starting point, not a cage)
| Time | Beat | What the viewer gets |
|---|---|---|
| 0–2 s | **Hook** | Frame 0 already shows the payoff composition, in motion. Hook spoken in the first second. |
| 2–8 s | **The familiar thing** | The everyday analogy, drawn simply. |
| 8–20 s | **The mechanism** | The camera dives into how it works. Something new every 1.5–3 s. |
| 20–26 s | **The payoff** | The key fact, on the biggest visual reveal. |
| 26–30 s | **Loop + action** | A question or "save this", then a flow back to frame 0. |

## Never
- A static title card at the start. Ep 9 did it and 63.6% of viewers skipped.
- More than 3 seconds without something new happening on screen.
- A plain dial with no mechanism.
- Text below y≈1200 except the captions (Instagram covers it).
- Any claim without a source in `facts.md`.

## Posting (Instagram)
See `posting.md`. In short: the cover is frame 0 or the payoff frame. The caption leads with the searchable keyword phrase. Use 3–5 targeted hashtags. Pin a first comment with the question. Ask for saves and sends: they count for more than likes.
