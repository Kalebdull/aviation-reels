# Posting notes (Instagram Reels)

Deliver these with every episode, in `episodes/<slug>/posting.md`.

| Field | Rule |
|---|---|
| **Cover** | Frame 0 or the payoff frame (export with `node scripts/render.mjs <slug> --stills <t>`). The keyword must be readable in the 4:5 grid crop (centre 1080×1350). |
| **On-screen keyword** | The topic phrase people search ("VOR TO FROM flag", "pitot static system") appears on screen and in the captions. |
| **Caption (first line)** | The hook as a question or promise plus the keyword phrase. 125 characters or fewer before the "more" cut. |
| **Caption (body)** | 2–3 short lines restating the payoff fact plus "Save this for your checkride ✈️" or "Send this to a student pilot". |
| **Hashtags** | 3–5, specific to broad: e.g. `#studentpilot #instrumentrating #flighttraining #aviation #pilotlife`. |
| **Pinned first comment** | The question from the end of the reel, or the quiz answer behind a "spoiler". |
| **Audio** | Original audio (the voice + bed). Title it with the topic. |
| **Timing** | Post when the audience is active (check Insights → Most active times). Post Part 2 within 1–2 days of Part 1. |

Log every post in `brain/episodes.md` (date, slug, hook formula), then add the numbers to `lessons.md` when they're in.
